# DevOps Internship - Task 5

## Host a Static Website with GitHub Pages

### Objective

Deploy a static website using GitHub Pages.

### Tools Used

* HTML
* CSS
* Git
* GitHub
* GitHub Pages

### Project Description

Created a simple, responsive static website using HTML and CSS. The source code is stored in GitHub and published using GitHub Pages.

### Features

* Custom header and footer
* Styled content card
* CSS styling
* Static website hosting

### Live Website

https://prameelarani07.github.io/github-pages-5/

### GitHub Repository

https://github.com/prameelarani07/github-pages-5

### Deployment Steps

1. Created an index.html file.
2. Initialized a Git repository.
3. Committed the website files.
4. Created a GitHub repository.
5. Pushed the code to GitHub.
6. Enabled GitHub Pages from the main branch and root folder.
7. Verified the live website in a browser.

### Outcome

Successfully hosted a static website using GitHub Pages.
